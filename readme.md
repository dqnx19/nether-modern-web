# Nether Web UI

Modern UI components for building responsive websites

## Features
- Ready-to-use UI components
- Responsive design
- Easy integration
- Lightweight
- Vanilla HTML, CSS & JavaScript

## How to use on your website
```html
<link rel="stylesheet" href="https://web-ui.nether.click/components/css/${component_name}">
```

```html
<script src="https://web-ui.nether.click/components/js/${component_name}">
```

##  Notes
> it is reccommended to download the source code file and place it in your project folder because the files from cdn can be modified with no backwards compatibility which can result into state when your code is not working correctly
